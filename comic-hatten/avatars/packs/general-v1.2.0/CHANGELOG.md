# 変更履歴：一般キャラクター素材セット

## 1.1.0 — 2026-10-12

- ジャケットとエプロンの反転を解除し、服装ごとの向きを修正。カジュアル服の補正は維持。
- 成人男性２種・中年男女・高齢男女の頭部６種と、顔６種を追加。
- 見本キャラを６人追加して計14人。頭部12 × 顔10 × 服３ × 髪色４ × 服色６＝8,640通り。
- 1.0.0〜1.0.2 の人物ID・パーツID・ブラウザ保存・設定JSONを引き継ぎ可能。

## 1.0.2 — 2026-10-12

- 体・足先と頭部が同じ方向を向くよう、身体だけを接合点のまわりで左右反転。
- 服装の `assemblyFlipX` に合成時の反転を明示。全体の `flip` 操作とは別に適用。
- 1.0.0 / 1.0.1 の保存データと設定JSONは引き継ぎ可能。

## 1.0.1 — 2026-10-12

- 頭と身体の二重の首が目立たないよう、接合点を襟元へ調整。
- 全６髪型の顔の配置・縦横比を調整。
- 肌の範囲を使って顔パーツを重ね、前髪と輪郭を保持。
- パーツID・人物ID・書き出し画像の寸法は維持。旧設定JSONを工房で読み込み可能。

## 1.0.0 — 2026-10-12

- 一般キャラクター用の独立パック `comic-hatten-general` を新設。
- 髪型を含む頭部６種、目・鼻・口をまとめた顔４種、服装３種を収録。
- 髪４色、服６色を組み合わせ、1,728 通りの見た目に対応。
- ８人の初期プリセットを追加。どのパーツも漫画家・編集者の両方に使用可能。
- 待機・歩行・仕事・喜びの４動作と、Canvas 2D 用の合成描画モジュールを収録。
- 固定 ID とパーツ ID を保持する人物 JSON、および合成済み８コマ PNG の受け渡し仕様を追加。
- 配布物の SHA-256、単独の表示例、本体担当 AI 向けの組み込み手順書を同梱。
- 能力・登場条件・採用費は本体側の担当とし、素材データでは未決定の `null` を維持。
- 固定６人の `comic-hatten-specialists` v1.0.0 と、その配布 ZIP は変更なし。
