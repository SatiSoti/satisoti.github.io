# コミック発展国

漫画出版社の経営シミュレーション。仕様書「漫画出版社経営ゲーム｜詳細仕様書・調整データ」第1.1版に沿って作り直した版です。

1996年、月刊誌一誌と六本の連載だけを持つ小さな出版社の社長になり、新連載を企画し、作家と編集者を育て、雑誌を増やして、ミリオンセラーと業界首位を目指します。

## 遊び方

`comic-hatten/` フォルダー全体をHTTP/HTTPSで配信し、`index.html` を開くと遊べます。ビルドは不要です。HTML単体や `file://` で開く方法では、アバター素材を読み込めません。

- 1ターンは1週、1年は52週です。「次の週へ」で1週ずつ進めるか、×1・×2・×4で自動に進めます（スペースキーで一時停止）。社長の判断が必要なときや資金が足りなくなりそうなときは自動で止まります
- 「企画会議」で新連載を企画します。物語タイプ24種 × 題材60種の組み合わせごとに★1〜5の相性と、その理由が表示されます
- 作者には意欲・信頼・疲労・コンディションがあり、4週ごとに担当編集との打ち合わせで方針を決めます
- 単行本は読者層ごとの購入希望・予算・在庫で売れ方が決まり、同じ市場でライバル4社（東雲出版・白帆書房・鉄塔社・風見社）と取り合います
- 映像化（アニメ・ドラマ・映画）は打診 → 契約 → 制作 → 放送の段階で進みます
- 2010年から電子版が解禁されます

セーブはブラウザの localStorage に自動で保存されます（13週ごと）。手動のスロット2つと、テキストへの書き出し・読み込みもあります。

旧v1のセーブデータは引き継がれません。現在のv2のセーブはアバター追加後も読み込めます。

## 確認待ちの調整

仕様の文言から意図的に変えた調整値（O-01〜O-30）は、「設定」画面の「開発者向けの画面を表示」から開く開発画面で一覧でき、それぞれ仕様どおりに戻す設定名も書いてあります。


## アバターと固有キャラクター

漫画家・編集者にパーツ合成アバターが付きます。作者画面、企画会議、編集者の採用候補、ホームの編集部で同じ姿を表示します。「人物図鑑」で自社の仲間と、これから登場する固有６人を確認できます。

一般キャラの髪型・顔・服装・色は人物ごとに決まり、セーブに保存されます。男性向け／女性向けの分類内で組み合わせます。v2の既存セーブも読み込め、名前・能力・資金・連載を維持したまま外見が付きます。

固有６人は開始からの経過週に応じて登場します。漫画家は通常の持ち込み企画から、編集者は「経営」の採用候補から迎えます。採用・連載開始の条件と費用はゲーム本体の仕組みを利用します。登場条件・能力値は `avatars/game-avatars.js` に分離しています。

画像と描画コードは `avatars/` 以下に同梱しています。配信時は `comic-hatten/` フォルダー全体を配置してください。パーツの読み込みにはHTTP/HTTPSが必要です。画像の読み込み中や失敗時も経営の操作は継続でき、編集部には簡易表示が残ります。

制作元の固定キャラパック v1.0.0、一般キャラパック v1.2.0 は `avatars/packs/` に原本のまま収録しています。制作管理帳・外部CDNへの接続は不要です。ゲームへの接続と検証の詳細は `avatars/INTEGRATION.md` を参照してください。
