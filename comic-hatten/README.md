# コミック発展国

カイロソフト風の漫画出版社経営ゲーム。1996年、雑誌一誌と看板作品一本だけの無名出版社の社長になり、連載を企画して雑誌を増やし、業界ナンバーワンを目指す。

## 遊び方

`index.html` をブラウザで開くだけで遊べる。ライブラリやビルドは不要。GitHub Pages を有効にすれば、そのURLでも遊べる。

- 時間は自動で進む。スペースキーで一時停止
- 「雑誌」タブで連載の顔ぶれを確認し、空き枠に新連載を企画する
- 作品名を押すと、方向性・担当編集・テコ入れ・宣伝・移籍・完結を決められる
- 新雑誌を創刊するときは、ラインナップ会議で10作を選ぶ
- 2010年から電子版とWebコミック誌、2013年から自社マンガアプリが登場する

セーブはブラウザの localStorage に自動保存される。
